# Literature notes (2026-11-16, web search; not full-paper reads: treat as leads)
- FX dealers/fund managers use technical analysis widely, mainly at short horizons; flows dominate the very short term, fundamentals the
  long term (Menkhoff & Taylor 2007, J. Economic Literature). No reliable ranking of indicators found.
- Simple, well-known technical rules (moving average, filter) earned excess returns in the 1970s-80s but were gone by the early 1990s
  out-of-sample; obscure rules decayed more slowly (Neely, Weller & Ulrich 2009, JFQA / St Louis Fed WP 2006-046).
- Institutional FX style premia: carry, momentum, value (and dollar). Carry strongest historically but crash-prone; trend/momentum hedges it;
  persistence of momentum varies by sample (Quantpedia, academic papers). Low turnover => costs small.
- Implication for this project: the v1/E1-E5 set was the "textbook" family; the cost model charged swap adverse both ways, so a carry-style
  strategy (which EARNS swap) was never testable. Hence batch 3 (E6 now, E7 once rate data is documented).
- Evidence that AI tools raise retail profitability is thin (survey: ~21% report improvement; vendor claims unverified).
